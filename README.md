# My Chrome Extension

## কীভাবে ইন্সটল করবেন (How to Install):

১. এই রিপোজিটরির ডান দিকের **Code** বাটনে ক্লিক করে **Download ZIP** সিলেক্ট করুন এবং ফাইলটি ডাউনলোড করে Unzip/Extract করুন।
২. আপনার ক্রোম ব্রাউজারে `chrome://extensions/` পাতায় যান।
৩. ডান দিকের উপরে থাকা **Developer mode** অপশনটি অন করুন।
৪. বাম দিকের **Load unpacked** বাটনে ক্লিক করুন।
৫. Unzip করা ফোল্ডারটি সিলেক্ট করে দিন।
